description: MonioInput for native Apple applications.

The repository also contains **MonioInput** in the [`swift/` directory](https://github.com/HuakunShen/monio/tree/main/swift).

This is a native Apple input layer for capture, injection, display enumeration and self-injection provenance. It is a sibling project, **not** a Swift binding around the Rust crate.

The Rust and Swift implementations share an input contract: neutral key naming and provenance conventions. This lets independent Swift and Rust processes on the same Mac agree about the identity and origin of keys.

Read the [Swift package README](https://github.com/HuakunShen/monio/blob/main/swift/README.md) for its APIs and setup.
